# Dose Buddy Backend

This is the Python backend for the Dose Buddy application.

## Requirements

- Python 3.8 or above

Install backend dependencies:

```bash
pip install -r requirements.txt
```

## Running the Backend

Start the backend server:

```bash
python main.py
```

The backend exposes REST API endpoints (see `main.py` for implementation). By default, it uses the SQLite database (`dosebuddy.db` or `dosebuddy_v2.db`).

## Endpoints

See source code for available endpoints and customize as needed.

## Development

- All backend code is in this directory.
- Keep requirements up to date in `requirements.txt`.
- Database schema is in the `.db` files.
